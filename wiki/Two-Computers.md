# Two computers

Many parishes run the sanctuary screen from one computer and the live
stream from another (the one connected to the streaming software or video
switcher). EpiscoPresenter keeps them in step: one computer runs the
service, and the other follows it, so every slide changes on both at once.

## Setting up

1. Put both computers on the **same network**. A wired connection is best.
2. On the **sanctuary computer**, click the connection words at the right
   of the top bar (**One computer**), or **⚙ Settings → Connection to the
   other computer…**. Choose **Sanctuary computer** and click **Save**. The
   app restarts.

   The window shows this computer's address, for example
   `Sanctuary-Mac-mini.local` or `192.168.1.20`. Note it down.
3. On the **live-stream computer**, open the same window, choose
   **Live-stream computer**, type the sanctuary computer's address, and
   click **Save**.
4. On each computer, open the screen it drives with the **monitor icon**
   at the right end of the top bar: the sanctuary screen on the sanctuary computer, the stream on
   the live-stream computer.

The first time, macOS asks whether EpiscoPresenter may find devices on the
local network and accept incoming connections. Choose **Allow** on both.

Also set up the **parish library folder** on the live-stream computer
(**⚙ Settings → Parish library folder…**). Pictures, PDFs and videos are
shown from each computer's own copy, and services marked ready in the
planner are copied to both.

## What the top bar says

| On | Says | Means |
| --- | --- | --- |
| Sanctuary computer | **Live stream connected ✓** | All is well. |
| Sanctuary computer | **Waiting for the live-stream computer** | The other computer isn't connected yet. |
| Live-stream computer | **Following … ✓** | All is well. |
| Live-stream computer | **Not connected to the sanctuary computer** | See below. |

Hover the words for the address and the delay between the computers.

## Using the live-stream computer

The live-stream computer shows the same window but follows the sanctuary
computer. It can press Next and Prev, use the buttons, and send stage
messages. Edit the service on the sanctuary computer.

## If it won't connect

* Check the address typed on the live-stream computer.
* Check both are on the same network (not one on guest Wi-Fi).
* Check the sanctuary computer's firewall allows EpiscoPresenter (on a Mac:
  System Settings → Network → Firewall).
* On a managed Mac, IT may need to allow local network access.

To go back to one computer, choose **One computer for both** in the
Connection window.
