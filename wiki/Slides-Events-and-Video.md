# Slides, events and video

These can go anywhere in a service (with the sermon, at the announcements)
or make up a whole event. They're not printed in the bulletin; the script
lists them by title.

## Events

For a gathering that isn't a service (a meeting, a concert, a parish
dinner): **Schedule services… → One service**, then **Service → Event (not
a service)**. It starts with one blank item of slides and no Prayer Book
order.

## Making slides

**+ Add → New slides (slide maker)** adds an item of slides and opens the
Editor, where each slide is a card with a preview. Choose a layout:

| Layout | Shows |
| --- | --- |
| **Title** | A large title in the middle, with an optional line under it |
| **Information with title** | A title at the top, then the information |
| **Information without title** | The information alone, using the whole screen |

The information is **Text** (a blank line starts a new paragraph) or a
**Picture** from the media library, sized **In the middle**, to the **Box
width**, the **Box height**, or **Full screen**.

**+ Add a slide** adds a card; ↑ ↓ move it, ⧉ copies it, ✕ deletes it. Set
the background and text colour in **Appearance**.

## PowerPoint, Keynote and Google Slides

* **+ Add → Slides from a PDF (PowerPoint, Keynote)…**: save the
  presentation as a PDF first (PowerPoint: File → Save As → PDF; Keynote:
  File → Export To → PDF). Each page becomes a full-screen slide.
* **+ Add → Google Slides presentation…**: paste the presentation's link
  (shared as *Anyone with the link can view*). **↻ Download again** in the
  Editor fetches it after changes.

Animations and videos inside a presentation don't carry over. You can add
your own slides among the imported ones in the Editor.

## Web video

**+ Add → Web video (YouTube, Facebook, Instagram)…** adds a video by its
link. On air it plays full screen, with sound from the sanctuary screen and
muted on the live stream. Moving on stops it.

* It needs the internet during the service, and the owner must allow the
  video to be embedded (most YouTube videos do).
* Instagram videos may need a click on the sanctuary screen to start.
* A video you have the right to download plays more reliably as a file:
  import it in **Library → Media** and add it from there.

## Pictures and videos from the media library

In **Library → Media**, select a file and click **Add to service** (both
screens) or **Add (sanctuary only)** (the stream shows the camera). See
[Library and media](Library-and-Media#media).
