# Events, made slides, imported presentations and web video

These are ordinary items: they can go anywhere in a service (for example
with the sermon) or make up an event. None of them is printed in the
bulletin; the script lists them by title.

## Events

For a gathering that is not a service (a meeting, a concert, a parish
dinner), choose **Service → Event (not a service)** under **New service**.
It has no Prayer Book order, readings or options: it starts with one blank
item of slides. Make the slides in the **Editor**, or add more items with
**+ Add**.

## Making slides

**+ Add → New slides (slide maker)** adds an item of slides and opens it in
the **Editor**, where each slide is a card with a preview:

| Layout | Shows |
| --- | --- |
| Title | A large title in the middle, with an optional line under it |
| Information with title | A title at the top, then the information |
| Information without title | The information alone, using the whole screen |

The information is **Text** (a blank line starts a new paragraph) or a
**Picture** from the media library, sized:

| Size | The picture |
| --- | --- |
| In the middle | at its own size (made smaller if it would not fit) |
| Box width | as wide as the information box |
| Box height | as tall as the information box |
| Full screen | filling the screen (the title is not shown) |

**+ Add a slide** adds a card; ↑ ↓ move it, ⧉ copies it, ✕ deletes it. The
background and text colour are set in **Appearance** in the Editor,
as for any item (they start as the dark glass with light text, on both
screens). Text shrinks to fit its box.

In the `.ewm` file a Title slide starts with `#`, Information with title
with `##`, Information without title with neither, with `---` between
slides; a picture's size follows it as `{center}`, `{width}`, `{height}` or
`{full}`: `![Map](library:media/map.png){width}`.

## Presentations from PowerPoint, Keynote or Google Slides

* **+ Add → Slides from a PDF (PowerPoint, Keynote)…**: save the
  presentation as a PDF first (PowerPoint: File → Save As → PDF; Keynote:
  File → Export To → PDF; Google Slides: File → Download → PDF). The PDF is
  copied into the media library and each page becomes a full-screen slide.
  PowerPoint files themselves cannot be read, and animations and slide
  videos do not carry over into a PDF.
* **+ Add → Google Slides presentation…**: paste the presentation's link (shared
  as "Anyone with the link can view"). It is downloaded as a PDF, one slide
  a page; **↻ Download again** in the Editor fetches it after changes. A
  computer downloads it the first time it shows it.

The slides are made slides with full-screen pictures, so you can add a
title slide or a slide of your own among them in the Editor. Next / Prev
step through them as through any item.

## Web video

**+ Add → Web video (YouTube, Facebook, Instagram)…** adds a video by its
link. When the item goes on air it plays full screen: with sound from the
sanctuary screen, muted on the live stream. Moving to another item stops it;
the previews show a still (YouTube) or a label.

* It needs the internet during the service, and the video's owner must
  allow it to be embedded (most YouTube videos do; private or
  age-restricted ones do not).
* Instagram embeds do not start on their own: they may need a click on the
  sanctuary screen.
* A video you have the right to download plays more reliably as a file:
  add it to the media library and use **+ Add → From library** / Media.
