Bundled background artwork, by liturgical colour.

`green/` holds the parish's designs. Sanctuary: `glass-light` (prayers),
`glass-dark` (readings, title cards), `glass-charcoal` (psalms). Stream:
`panel-dark` (prayers), `panel-light` (hymns), `bar-bottom` (psalms,
Eucharistic Prayer, Gospel), `lower-third` (readings, sermon, announcements,
dismissal, on a blue key) and `window` (welcome / postlude).
They replace the drawn built-in designs of the same names when a cue's colour
is Green. See `ARTWORK` in `ui/js/backgrounds.js` and docs/backgrounds.md.

Service-specific images belong in a `backgrounds/` folder beside the service
plan, not here.
