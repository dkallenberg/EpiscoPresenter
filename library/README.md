Built-in library items: texts from the Holy Eucharist, Rite Two, of the
1979 Book of Common Prayer (public domain). They are compiled into the app
and appear in the Library tab as "Built-in". Items you save from the app go
into your own library folder instead; see docs/library.md.

To add a built-in item, put an `.ewm` file here and list it in
`src-tauri/src/library.rs` (BUILTIN).
